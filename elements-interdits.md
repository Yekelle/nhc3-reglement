# Éléments interdits

Cette page présente les pratiques, logiciels et comportements interdits pendant la Nuclear Haunted Cup 3.

## Modifications visuelles

Sont interdits :

- les shaders ;
- les filtres externes améliorant la luminosité ;
- les logiciels modifiant artificiellement l’affichage du jeu ;
- tout réglage extérieur à Phasmophobia procurant un avantage visuel.

## Glitchs et usebugs

L’utilisation volontaire d’un glitch, d’un usebug ou d’un emplacement permettant de contourner les mécaniques normales du jeu est interdite.

Les exemples précis de comportements interdits seront ajoutés au règlement avant le tournoi.

En cas d’utilisation accidentelle, le participant devra prévenir immédiatement son modérateur.

## Aide extérieure

Sont interdits :

- le backseat du chat ;
- les informations transmises par une autre personne ;
- les informations provenant d’un autre stream ;
- les outils interactifs permettant aux spectateurs d’influencer l’enquête ;
- toute aide extérieure permettant d’identifier le fantôme ou de remplir un objectif.

Les règles détaillées concernant le chat seront présentées dans une section spécifique.

## Décision de l’organisation

En cas de doute, l’équipe d’organisation déterminera si un outil ou un comportement procure un avantage contraire à l’esprit du tournoi.
