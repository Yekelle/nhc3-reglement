# Règles concernant le chat

Afin de garantir l’équité entre les participants, aucune aide provenant du chat ne pourra être utilisée pendant les enquêtes.

## Backseat interdit

Les spectateurs ne doivent pas :

- proposer un type de fantôme ;
- rappeler une preuve ou un comportement observé ;
- signaler qu’un objectif est terminé ;
- corriger la sélection du participant ;
- transmettre une information provenant d’un autre stream ;
- donner une indication pouvant influencer l’enquête.

## Fonctionnement du chat pendant les parties

Le dispositif appliqué pendant les enquêtes sera précisé avant le tournoi.

Les solutions actuellement envisagées sont :

- le passage du chat en mode emotes uniquement ;
- la mise en place d’une liste de mots bannis ;
- une modération renforcée du chat.

Le chat pourra fonctionner normalement entre les parties, sauf indication contraire de l’organisation.

## Information donnée sans être demandée

Un participant ne sera pas automatiquement sanctionné lorsqu’un spectateur publie une aide sans son accord.

Il ne devra cependant pas exploiter volontairement cette information.

Si l’aide influence manifestement une décision prise pendant l’enquête, l’organisation pourra examiner la situation.

## Responsabilité du participant

Le participant devra respecter le dispositif choisi par l’organisation et prévenir immédiatement son modérateur en cas de problème concernant son chat.
